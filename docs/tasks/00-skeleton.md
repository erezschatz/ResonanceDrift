# 00 · Skeleton and documentation

## Promise
A repository that a fresh session — human or Claude — can open and understand
without this conversation: what is being built, why, in what order, and how to
set up the machines.

## Acceptance
- [x] Gradle project with version catalog, wrapper, shared debug keystore
- [x] Placeholder `MainActivity` and light theme; one ported behaviour
      (`AlbumNames`) with unit tests, so the toolchain can be proven
- [x] `docs/SPEC.md`, `docs/DECISIONS.md`, `docs/PLAN.md`, `docs/tasks/`,
      `docs/AMPACHE.md`, `docs/REDRIFT.md`, `docs/SETUP.md`, `CHANGELOG.md`
- [x] `CLAUDE.md` describes the working discipline and the per-commit checklist

## Notes
Written without an Android SDK; the skeleton had never been built when this
step was marked done. Step 01 is where that is verified.
